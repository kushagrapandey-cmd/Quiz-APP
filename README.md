# Timed Quiz

A standalone JavaScript quiz with three general-knowledge questions.

## Features

- Shuffled questions and answer choices.
- Ten-second timer per question.
- Progress indicator, score calculation and restart.
- Answer selection can be changed before advancing; the score reflects the current choice.

## Run

Open `index.html` in a browser. `script.js` contains the questions and game logic; `styles.css` controls presentation. No installation, API or database is required.

For the larger anime quiz and game project, see [WWW-of-Anime](https://github.com/kushagrapandey-cmd/WWW-of-Anime).
